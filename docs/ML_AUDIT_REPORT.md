# Historical: Local ML Audit

**Status: archived pre-STRATHMARK-v2 evidence.**

The previous contents described a pre-v7 experiment. They remain available in Git history and dated v6 audit/release material. They are not a current runtime contract.

STRATHEX 7 uses STRATHMARK 2's prior-only hierarchical core, fixed evidence cutoff, calibrated interval, performance spread, and joint optimizer. Numeric Ollama/LLM prediction, local XGBoost selection, expected-error comparison, QAA scaling, block-quality adjustment, and 97/3 same-tournament weighting are retired.
