# STRATHEX 7.2.0 — 2026-10-02

The app now supports an explicit Linux V3 numeric candidate alongside V2.
Both choices use persisted competition authority, inherited by children and
locked before numeric work. The separate V3 interpreter executes real Formula,
verified trained ML, distribution pooling, and field optimization. Pre-field
seeding carries no marks; exact fields produce proposed marks. A saved event
retains its workbook snapshot and code/model identities after restart.

Local V3 output is **NUMERIC PREVIEW ONLY**. It cannot approve, issue, record
or settle official results, export official start schedules, or learn from the
next round. The full authenticated V7 lifecycle and production qualification
remain separate. No accuracy qualification or production cutover is claimed.
Private historical data and trained models are not included in the release.

The V2 dependency remains the exact STRATHMARK 2.0.0 Git release pin.
UH/SB inputs now map correctly to canonical V3 contexts. Both Linux and Windows
CI run installed distributions and synthetic training/inference, in addition
to existing V7 transport/recovery checks.

See [V3 setup](V3_REHEARSAL.md) for installation, training, and verification.
