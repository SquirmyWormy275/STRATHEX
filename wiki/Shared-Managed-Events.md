# Shared managed events

STRATHEX's retro CLI, workbook and existing V2/V3 saves retain their authority.
New synthetic delegated sessions can explicitly launch the shared STRATHMARK
CLI or authenticated workspace against one persistent event. There is no
implicit save migration or runtime fallback.

See [setup and launch commands](https://github.com/SquirmyWormy275/STRATHEX/blob/main/docs/MANAGED_EVENTS.md)
and [the cross-repository agreement](https://github.com/SquirmyWormy275/STRATHMARK/blob/main/docs/MODULAR_ECOSYSTEM.md).
